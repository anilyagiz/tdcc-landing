Marketplace FAQ

Before you rent.

What is the difference between renting and running a job?

Renting gives you the machine for a period of time and you run whatever you like on it. Running a job means you describe the work, TDCC picks matching hardware, and you pay only when the result passes its acceptance checks. Both use the same hosts and the same account.

Are these prices final?

No. The marketplace is in early access and the prices shown are indicative. We confirm the hardware and the price with you before a rental starts.

What happens if a host goes offline during a job?

Jobs are requeued to another host automatically, and work that fails verification is not billed. For rentals we confirm the terms with you when the request is accepted.

What is an Exact Core listing?

Exact Core is TDCC's own accelerator card. Its output can be replayed bit for bit on a laptop, so a renter can check that the work was actually done. Jobs on it are paid through USDC escrow on Solana. Read the announcement.

Do I need a wallet?

No. Rentals and regular jobs work with a normal TDCC account. Only Exact Core jobs settle on Solana today.
